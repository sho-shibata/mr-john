Sho Shibata（以下、「当方」といいます。）は、株式分析＆クオンツAIターミナル「Mr.John Stock Research」（以下、「本サービス」といいます。）における、ユーザーの個人情報の取扱いについて、以下のとおりプライバシーポリシー（以下、「本ポリシー」といいます。）を定めます。

🔒 クレジットカード情報の非保持について
当方は、有料プラン決済において国際セキュリティ基準 PCI-DSS に準拠した Stripe, Inc. の決済代行システムを利用しています。お客様のクレジットカード番号、有効期限、セキュリティコード等は当方のサーバーには一切送信・保存されず、Stripe社によって最高水準の暗号化環境で安全に直接処理されます。

第1条（収集する情報および収集方法）

当方は、本サービスの提供にあたり、以下の情報を取得することがあります。

  • アカウント登録情報: メールアドレス、ユーザー名、パスワード（bcryptアルゴリズムにより不可逆暗号化ハッシュとして保存）
  • ソーシャルログイン情報: Google または GitHub アカウント連携時のユーザー識別子、公開メールアドレス
  • 決済識別情報: Stripeが発行する顧客ID（Customer ID）、サブスクリプションID、契約ステータス（クレジットカード番号自体は非保持）
  • 利用ログ情報: IPアドレス、ブラウザ種別、アクセス日時、仮想トレード操作ログ、SQL実行ログ、AI診断実行履歴
  • 外部通知設定: ユーザーが設定したSlackまたはDiscordのWebhook URL（売買アラート用）

第2条（個人情報の利用目的）

当方は、取得したユーザー情報を以下の目的で利用します。

  1. 本サービスのアカウント認証、セッション管理、および機能アクセスの権限制御（Free/Pro/Maxプラン）
  2. 有料サブスクリプションプランの請求処理、課金管理、領収書発行（Stripeカスタマーポータル連携）
  3. 仮想トレードボットの売買シグナル通知およびアラート配信（Slack, Discord, Email）
  4. 本人確認、メールアドレスの有効性確認（Email Verification）、および不正利用・スパムの防止
  5. システムの障害対応、パフォーマンス監視、セキュリティ監査、およびサービス改善のための統計分析
  6. 重要なお知らせ、規約改定等のご連絡

第3条（外部委託および第三者サービスとの連携）

当方は、利用目的の達成に必要な範囲において、以下の信頼性の高い第三者サービスを利用・連携しています。

  • Stripe, Inc.（決済処理基盤）: クレジットカード決済およびサブスクリプション課金管理のために利用します。
  • Google LLC（Google Gemini API）: 企業の財務諸表および開示テキストの定性分析・AI診断生成のために利用します。利用者の個人特定情報は送信されません。
  • メール配信基盤（SMTP / Gmail）: メールアドレス認証トークンの送信、および取引アラート配信のために暗号化通信（TLS）経由で利用します。

第4条（安全管理措置）

当方は、取得した個人情報の漏洩、滅失または毀損の防止その他の安全管理のために、以下の技術的措置を講じています。

  • 全通信経路における SSL/TLS による暗号化
  • パスワードの bcrypt アルゴリズムによる不可逆ソルト付きハッシュ化
  • JSON Web Token（JWT）および HMAC-SHA256 署名によるセキュアな認証トークン発行
  • ロールベースアクセス制御（RBAC）によるデータ操作権限の厳格な分離

第5条（Cookie等の利用）

本サービスは、ユーザーのログイン状態の維持、セッション管理、およびダッシュボード表示設定の保存のために、Cookieおよびブラウザのローカルストレージ（LocalStorage）を使用します。利用者はブラウザ設定によりCookieを無効化できますが、その場合ログインを伴う機能が正常に動作しない場合があります。
